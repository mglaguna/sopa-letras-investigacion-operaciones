Actividad de aplicación

Una planta química produce dos productos: A y B.

El producto A genera una utilidad de $40 por unidad y el producto B genera $30.

Si se producen 20 unidades de A y 60 unidades de B, ¿cuál es la utilidad total?

Consultar explicación

Z = 40(20) + 30(60) = $2,600.

Este ejemplo utiliza datos hipotéticos para fines didácticos.
